## 问字

中文模式下以问字键 `u` 开头，再用拼音输入问题：

- `usangemushishenmezi`（三个木是什么字）
- `umumumu`（报部件）
- `ufaguoshoudu`（短事实问答）

停顿后云端返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。

`?` 缺省只是问号。在「偏好设置 → 快捷键」勾选「没在输入拼音时敲 ? 也进入问字」后，未输入拼音时输入 `?` 再接拼音同样进入问字，
中英文模式下均可用。双拼下 `u` 是音节键，问字改用 `Shift`+`U` 再接拼音。此时输入 `?` 之后接的不是字母时，它还原为普通问号输出（中文模式遵循「默认中文标点」设置，英文模式使用半角）：
`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

未打开云联想时同样可进入问字，但不会得到答案，`Enter` 输出原文。

## 翻译选中的文字

在「云服务」页开启「翻译选中文字」，并选择「选区翻译渠道」。可选「共用大模型云服务」或「Youdao公共渠道」。前者使用同页填写的地址、模型与密钥；后者将选中文字直接发送给有道，不需要密钥。
有道支持译为英语、日语、西班牙语或译回中文，与释义补全共用排队，连续请求可能需等待。公开服务可能限频或暂时不可用，失败时不自动改用大模型。
它不依赖候选词联想或整句补全开关。关闭后，翻译快捷键原样交给应用。

配置文件对应：

```toml
[predict.translation]
enabled = true
channel = "llm" # 使用有道时改为 "youdao_public"
```

在应用中选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）：

- 选区以汉字为主时译为学习语言（英语、日语或西班牙语）；假名或拉丁字母不少于汉字时译回中文。翻译遵循这个方向；原文已经是目标语言时保持原文。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选区；`Esc` 保留原文；其他键放弃翻译并正常交给应用。

云服务或选区翻译关闭、密码框、应用不支持读取选区（部分 Electron 应用）时，快捷键原样交给应用。快捷键在「偏好设置 → 快捷键」可修改；
Windows 上修改后需切换到其他输入法再切回青简（或重启应用）才生效。

## 译词上屏托底

在「云服务」页开启「译词上屏托底（整句包含在内）」后，若候选完全没有译词，使用「选区翻译渠道」翻译该候选或整句，译文返回后自动上屏。高亮候选的译词上屏操作，以及修饰键加序号上屏第一、第二条译词，均支持托底。

默认关闭，需要开启云服务；与「翻译选中文字」开关独立。汉字为主时译为学习语言，外文译回中文，使用有道公共渠道时无需密钥。已有第一条译词但缺少第二条时不会触发托底。

等待期间保留当前输入，翻译成功后只消耗所选候选对应的内容；继续敲键、取消、切换焦点或渠道会作废旧结果。翻译失败时保留输入，不自动上屏原词。有道连续请求可能需排队。Windows 升级后需重新打开应用才能使用该功能。

```toml
[predict]
enabled = true
translation_commit_fallback = true

[predict.translation]
channel = "youdao_public" # 或 "llm"
```
