云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

「偏好设置 → 云服务」：打开开关，填写服务地址、模型、API 密钥。缺省为 DeepSeek，任何 OpenAI 兼容的服务均可。
密钥只保存在本机，不随配置文件导出。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

发送的内容：所敲字母、本机的切分、光标前后各几十个字的上下文、本机给出的候选。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 联想与整句补全场景

在「云服务」页打开「联想 & 整句补全场景」，在「常用场景」中填写平时打字的主要场景，例如 `日常聊天，我的世界游戏，IT 行业`，用逗号或分号分隔，可填写中文或英文。
开启后，这些场景会随中文联想、中文整句补全和英文补全请求发送给所配置的服务商，帮助模型选择贴近你习惯的词语和表达。当前输入和光标上下文优先，不会强行套用场景。默认关闭；关闭或留空时不发送场景，关闭开关后已填写的内容仍保留。问字、翻译和译词自动补充不使用这些场景。

配置文件对应 `[predict]` 中的 `scenarios_enabled = true` 和 `scenarios = "日常聊天，我的世界游戏，IT 行业"`。

## 云端候选词

「中文云端候选词联想」和「英文云端候选词联想」可以分别开关，也各自独立于整句补全。中文默认开启，英文默认关闭。
配置文件对应 `[predict]` 的 `chinese_words` 和 `english_words`。同一语言的候选词与整句补全都关闭时，普通输入不发送该语言的预测请求。问字仍可单独触发。
云端词格数设为 0 时，中英文都不请求词候选，整句补全仍按各自开关工作。

英文候选补全当前单词，例如 `prog` → `programming`，保留输入的大小写。选中后记入个人英文词表，之后可以在本地给出。

输入拼音时停顿 300 毫秒后，云端给出的词补入当前候选页**末尾**两格（「云服务」页可调为 0 至 4），带云朵标记，数字键正常选择，上屏消耗整段拼音。

每次请求的候选词数量上限与设定的云端词格数一致，不额外多要。翻到另一页时会再次联想（方向键跨页也一样），发送前面各页和当前页的全部候选，以及本轮输入中云端已经猜过的词，避免反复给出相同候选；各页结果保留在对应页。继续编辑同一段输入时保留猜词历史，上屏、清空或切换输入上下文后清除。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 只敲声母（简拼，如 `fhyq`）时云端不再给词，只给整句补全——按声母凑出来的词大多不是真词。

## 整句补全

「云服务」页的「中文整句补全」与「英文整句补全」可独立开关，分别对应配置文件 `[predict]` 的 `sentence` 和 `english_sentence`，默认均开启。关闭中文整句补全仍可使用云端候选词；英文整句补全关闭后不发送英文补全请求。两者共用服务地址、模型、密钥和常用场景。

候选词联想与整句补全同时开启时，一次请求返回两者；只开其中一项时只请求对应内容。整句补全给出以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。有应用上下文时接着上下文续写，中文补全始终用中文，英文补全始终用英文；没有可靠补全时不显示建议。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），能可靠翻译时，返回的译词存入本机的个人释义表，下次候选旁即有显示；无法可靠翻译时不补充。
「缺失释义补全」可单独关闭；关闭后已有本地译词继续显示。
「释义补全渠道」可选择「共用大模型云服务」或「Youdao公共渠道」。前者使用同页填写的服务地址、模型和密钥；后者直接向有道发送该词，不需要密钥。
有道返回的简短译词会保存到本机；不提供词性和日语读音，过长或不合适的结果不保存。两种有道翻译共用排队，连续请求可能需等待；公开服务可能限频或暂时不可用，失败时不自动改用大模型。
配置文件对应：

```toml
[predict.gloss]
enabled = true
channel = "llm" # 使用有道时改为 "youdao_public"
```

「翻译选中文字」也有独立开关和渠道，见 [问字与翻译](question-and-translate.md)。两种翻译不需要开启候选词联想或整句补全。
「译词上屏托底（整句包含在内）」可独立开启，缺少全部译词时会使用选区翻译渠道翻译候选或整句，并在返回后自动上屏。默认关闭，具体操作见 [译词上屏托底](question-and-translate.md#译词上屏托底)。
关闭云服务总开关后，所有这些功能均停止发送新请求。

## 不联想的情况

上屏之后不联想；以 `v` 开头的算式不联想；密码框中不联想。英文预测由英文候选词和英文整句补全开关控制。
