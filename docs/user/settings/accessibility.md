在「设置 → 辅助功能」分别开启「截图通用 OCR」和「通用语音识别」，选择识别渠道。两项功能默认关闭，目前提供「有道公开接口」，无需 API 密钥，也不需要开启云联想。

快捷键在「设置 → 快捷键」修改，可分别选择修饰键与字母 / 数字，也可选择关闭。保存后自动生效；若组合已被其他程序或系统占用，会提示更换。
功能开启且青简在后台运行时，即使当前使用其他输入法也可触发。

## 截图识别文字

按 **Ctrl + Shift + S**，屏幕固定在触发时的画面，并覆盖暗色蒙层。按住鼠标左键拖出矩形，框内显示清晰原图，松开左键开始识别。
蒙层和选区都拦截鼠标，不会点到下面的应用；支持跨显示器框选。

按 **Esc** 或鼠标**右键**取消；切换到其他应用也会退出框选。取消时不上传图片、不改剪贴板。

## 录音转文字

先选择中文或英文，然后按 **Ctrl + Shift + H** 使用默认麦克风录音。屏幕提示录音状态与时长。

- 按 **空格**结束录音并识别。
- 按 **Esc** 或鼠标**右键**取消，不提交录音。
- 最长 **60 秒**，到时自动结束并识别。

无法录音时，请检查默认麦克风与 Windows 中已设置的麦克风权限。录音结束或取消后立即释放麦克风。

## 识别结果

非空结果自动复制到剪贴板；若原来的输入框仍可编辑、输入目标未改变，也会尝试在光标位置写入，有选中文字时替换选区。
切换了输入框、控件不支持自动写入或系统权限不允许时，结果仍在剪贴板，按 Ctrl + V 手动粘贴。
识别返回时若仍按着 Ctrl、Shift、Alt 或 Win，也会保留为手动粘贴，避免触发其他组合键。

识别期间按 Esc 或右键仍可取消。空结果、取消或识别失败不覆盖原剪贴板；同一时间只能进行一项识别任务。

所选图片或录音会通过网络发送给有道；图片与录音不保存在本机，识别正文不写入日志。
有道公开网页接口可能限频或暂时不可用，出现提示后请稍后手动重试。
